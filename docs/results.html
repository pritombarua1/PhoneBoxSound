  PAD -- "input, if allowed" --> HUB --> DESK
  EXT <-- "tabs, only on this PC" --> HUB
  MIC <-- "voice" --> HUB

How every phone plays at the same moment

sequenceDiagram
  participant PC as PC (clock)
  participant P as Phone
  loop every half second
    P->>PC: ping (my time)
    PC->>P: pong (your time, PC time)
    Note over P: keeps only the fastest round trips, offset = PC time minus my time
  end
  PC->>P: sound block, stamped "captured at T"
  Note over P: plays it at T + sync buffer, converted to the phone's own audio clock
  Note over P: small drift is absorbed by playing 0.4 % faster or slower, never by a jump

Screen view against the sound

A phone with a slower processor watches a detailed, fast-changing screen through a simulated Wi-Fi link (one shared queue at the router, the way real Wi-Fi works). Counted from the first second.

These run on one machine, so they measure PhoneBoxSound itself. A real home network adds its own delays; the sync buffer exists to absorb them.

Check it yourself

Everything above can be repeated on your own PC with the source code (download it from GitHub, then run start.bat once so everything is installed).

See it without phones: demo mode

Synthetic music, a pretend player and a pretend desktop. Open the address it prints in a few browser tabs, or on your phones:

python -m phoneboxsound --demo

Many phones at once

python scripts/loadtest.py
python scripts/loadtest.py --phones 100 --seconds 30

Screen view against the sound

node scripts/screencheck.mjs --busy --cpu 2 --mbps 4
node scripts/screencheck.mjs --busy --cpu 4 --mbps 3      (harsher: very slow phone, weak Wi-Fi)

Everything else

npm test             (unit tests)
npm run docs         (158 end-to-end checks in a real browser, with multi-touch; also remakes the screenshots)

Scenarios worth trying on your own network: one phone far from the router while another shows the PC screen; ten phones at once; a phone switching to another app and back; the PC going to sleep and waking. The dashboard's Devices page shows each phone's connection, and the Activity page records what happened.
