# Code of conduct

PhoneBoxSound welcomes everyone who wants to use it, report problems or help improve it.

**Please:** be kind and patient, assume good intent, keep discussions about the work, and accept that
the maintainer decides what goes into the project.

**Not accepted:** insults, harassment, discrimination of any kind, threats, sharing other people's
private information, spam, and asking for help to use PhoneBoxSound against people who did not agree
to it (spying, getting into someone else's device, harassment).

**What happens:** comments, issues or pull requests that break these rules can be edited, hidden or
removed, and their authors blocked from the project.

**Reporting:** open an issue, or for anything private use the contact on the maintainer's GitHub
profile (https://github.com/pritombarua1). Security problems: see [SECURITY.md](SECURITY.md).
